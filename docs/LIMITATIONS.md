# Limitations

Written deliberately before anyone asks. If a claim is not in here, we think it holds; if it is in here, we do not claim it.

## 1. Everything is in silico

No real patient data is used anywhere in this project. Every patient is generated by `src/generate_wearables.py`. All reported performance reflects our simulator's assumptions and should be read as an **upper bound** on what the same pipeline would achieve on real recordings.

## 2. The headline result depends on a coupling we encoded

The non-dipper screen reaches AUROC 0.963 because the simulator encodes a blunted nocturnal RMSSD rise in non-dippers (`PHENO_HRV` in `generate_wearables.py`). Reduced nocturnal parasympathetic activity in non-dippers is attested in the physiology literature, but **the effect size is our choice**. This result is evidence that the pipeline works end to end. It is not evidence about real patients.

We discovered this the honest way: our first version did not encode the coupling, and the screen scored AUROC 0.510, which is chance. We added the physiology because it was missing, not because the number was low, and we report both runs here so the reader can judge that for themselves.

## 3. Cuff-free forecasting does not work

Fusing cuff-free wearable data with the EHR gives AUROC 0.754 against 0.753 for the EHR alone. The confidence intervals overlap almost entirely. We report this as a failed hypothesis rather than presenting the fused number on its own. A one-line rule on yesterday's mean SBP scores 0.888, which beats every model we trained that lacked cuff access.

## 4. Two counterfactual arms we do not claim

- **Salt is circular.** The twin's coefficient (0.95 mmHg per gram) and the simulator's coefficient are both drawn from the same literature value. MAE of 0.00 mmHg on that arm measures nothing.
- **Sleep over-predicts.** 76% sign agreement and the twin over-states the benefit, because it over-amplifies the AR(1) carry-over in sleep-debt accumulation.

An earlier version also got the **sign of the activity effect wrong**, because same-day step count is confounded by the acute exercise pressor response and by awake time. We fixed it by regressing on lagged activity with awake hours as a covariate. It is recorded here because the original error is instructive.

## 5. The twin is a reduced model

No baroreflex dynamics, no renal or RAAS pathway, no beat-to-beat haemodynamics, no drug–drug interaction. Pharmacodynamics are a single rise-to-peak-then-decay shape per agent at steady state. The model is sufficient to express dose timing and circadian structure, which is what the counterfactuals need, and not more.

## 6. Cohort is not population-representative

Phenotypes are drawn 42 / 40 / 18 percent dipper / non-dipper / reverse-dipper, which is skewed toward non-dipping as in treated hypertensive cohorts rather than the general population. Comorbidity rates (T2DM 23%, CKD-3 13%, OSA 9%) are plausible but not calibrated to any specific Indian registry. 300 patients over 21 days is small.

## 7. Label definition is a modelling choice

We define the adverse event as sustained SBP ≥ 160 mmHg for ≥ 30 minutes. Hypertensive urgency (≥ 180) is reported as a rarer secondary at 6% of patient-days, but it is too sparse at this cohort size to model reliably. Different thresholds would give different numbers.

## 8. Clinical status

This is a research prototype. It is not a medical device, it has not been validated in humans, it has no regulatory clearance, and nothing in it should be used to make a treatment decision. The dose-timing simulation illustrates a mechanism; chronotherapy in real patients remains an area of active and unsettled trial evidence, and we take no position on it.

## What would change our minds

Paired ABPM and wearable recordings from an Indian hypertensive cohort. If the night/day RMSSD ratio does not separate dippers from non-dippers in real data, the screen does not work, and we would publish that result.
